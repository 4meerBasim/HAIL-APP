# Project Docs

Rules that govern how work gets done on Hail. `CLAUDE.md` imports every file
here, so they load as always-on context.

| File | Purpose |
|---|---|
| `agents-and-tasks.md` | How to plan a task, which subagent to use, the default workflow, definition of done |
| `code-review.md` | What to check, when review is allowed, this project's specific traps |
| `github-rules.md` | Branch strategy, commits, pushing, PRs |
| `obsidian-vault-rules.md` | The handoff vault — categories, status, colours, linking |
| `never-do.md` | Hard rules requiring explicit permission |

The vault itself is `vault/`, committed alongside the code.
